# مقاسي — نسخة تجريبية لقياس التيشرت بالكاميرا

النسخة دي هدفها حاجة واحدة: نعرف **مقاسي بيقيس التيشرت المفرود بدقة قد إيه** مقارنة بالمتر، قبل ما نبني التطبيق الكامل.

```
maqasi-poc/
├── server/   Python (FastAPI + OpenCV): بيستلم الصورة ويطلّع القياسات
├── app/      Expo + React Native (development build): كاميرا، مقياس، نتيجة، سجل تجارب
└── docs/     نتايج الاختبار
```

## إزاي القياس شغال

1. **التصوير:** الموبايل لازم يكون موازي للأرض. زرار التصوير بيتقفل لو الميل أكتر من 3°، لأن الميل هو أكبر مصدر للخطأ (شوف `docs/accuracy-synthetic.md`).
2. **المقياس (سنتيمتر لكل بكسل):** في النسخة دي بتضغط على نقطتين معروف المسافة بينهم، زي علامة 0 و50 على متر مفرود جنب القطعة.
   ده بيعزل سؤال "هل كشف القطعة دقيق؟". في التطبيق الحقيقي المقياس هييجي من الـ AR (ARKit/ARCore) — ده المرحلة الجاية.
3. **السيرفر:** بيفصل القطعة عن الأرضية، يعدّل ميلها، ويقيس:
   - عرض الصدر (2.5 سم تحت الإبط)
   - عرض الحافة (2 سم فوق آخر القطعة)
   - الطول (من أعلى الكتف جنب الياقة لآخر القطعة)
   - طول الكم (تجريبي — لسه مش دقيق)

## 1) شغّل السيرفر

```bash
cd server
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

أو بـ Docker: `docker build -t maqasi-server server && docker run -p 8000:8000 maqasi-server`

الاختبارات: `cd server && python -m pytest -q` — وجدول الدقة: `python -m tests.report`

الموبايل والكمبيوتر لازم يكونوا على نفس الواي فاي. عنوان السيرفر هيبقى `http://<IP الكمبيوتر>:8000`.

## 2) شغّل التطبيق على موبايل حقيقي

> **مش هيشتغل على Expo Go** — الكاميرا (VisionCamera) native module، فمحتاج development build.

```bash
cd app
npm install
```

**الطريقة الأسهل (من غير Android Studio / Xcode):** EAS Build

```bash
npm i -g eas-cli
eas login
eas build --profile development --platform android   # بيطلعلك لينك APK تنزّله على الموبايل
npx expo start --dev-client                           # افتح التطبيق وامسح الـ QR
```

**أو محلياً** (محتاج Android Studio أو Xcode): `npx expo run:android` أو `npx expo run:ios`

## 3) بروتوكول الاختبار

1. افرد تيشرت على أرضية سادة بلون مختلف عنه، والأكمام مفرودة للجنب، ومفيش كسرات.
2. حط متر مفرود على الأرض جنب القطعة (للمقياس في النسخة دي).
3. قيس بالمتر: عرض الصدر (2.5 سم تحت الإبط)، عرض الحافة، الطول، طول الكم.
4. في التطبيق: صوّر ← اضغط على 0 و50 على المتر ← "قيس القطعة" ← اكتب قياساتك بالمتر ← احفظ.
5. كرّر على **20 قطعة على الأقل** بألوان وأقمشة مختلفة، وعلى أكتر من موبايل.
6. الرئيسية بتعرض متوسط الخطأ لكل قياس ونسبة التجارب اللي خطأها ≤ 1 سم. صدّر النتايج JSON وابعتها.

**معيار النجاح المقترح:** الصدر والطول والحافة خطأهم ≤ 1 سم في 80% من التجارب.

## المرحلة الجاية

- المقياس من الـ AR بدل المتر (ViroReact أو native module بسيط بيقرأ مستوى الأرض)، ونقارن الاتنين على نفس القطع.
- تحسين قياس الكم، وإضافة البنطلون.
