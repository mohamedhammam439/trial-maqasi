# مقاسي — نسخة تجريبية لقياس التيشرت بالكاميرا

النسخة دي هدفها حاجة واحدة: نعرف **مقاسي بيقيس التيشرت المفرود بدقة قد إيه** مقارنة بالمتر، قبل ما نبني التطبيق الكامل.

```
maqasi-poc/
├── server/   Python (FastAPI + OpenCV): بيستلم الصورة ويطلّع القياسات
├── app/      Expo + React Native (development build): كاميرا، مقياس، نتيجة، سجل تجارب
└── docs/     نتايج الاختبار
```

## إزاي القياس شغال

1. **التصوير:** الموبايل لازم يكون موازي للأرض. زرار التصوير بيتقفل لو الميل أكتر من 3°، لأن الميل هو أكبر مصدر للخطأ (شوف `docs/accuracy-synthetic.md`).
2. **المقياس (سنتيمتر لكل بكسل):** بتختار المرجع اللي حاطه جنب القطعة:
   - **متر:** بتضغط على نقطتين معروف المسافة بينهم، زي علامة 0 و50.
   - **ورقة A4** (21 × 29.7 سم): السيرفر بيلاقي الورقة لوحده، أو تضغط على أركانها الأربعة.
   - **كارت بنكي** أو أي كارت بمقاس الفيزا (8.56 × 5.4 سم): زي الـ A4، بس أقل دقة لأنه صغير في الصورة
     (خطأ بكسل واحد في الحرف ≈ 1.3% من المقياس، يعني حوالي ±0.7 سم في صدر 55 سم، مقابل حوالي 0.4% للـ A4). التطبيق بينبّه على ده.
   - **حاجة تانية** مستطيلة معروف مقاسها: بتكتب طولها وعرضها.

   الأركان اللي بتضغط عليها بإيدك السيرفر بيظبطها على حروف الحاجة الحقيقية (لأن الضغطة على الشاشة بتغلط كذا بكسل).
   **حط المرجع مفرود ولازق في القطعة جنب الصدر:** لو الموبايل مايل شوية، المقياس بيتغير كل ما تبعد عن نص الصورة
   (ميل 3° ومرجع على بعد 50 سم من نص القطعة ممكن يغلّط المقياس 2–3%).
3. **السيرفر:** بيفصل القطعة عن الأرضية، يعدّل ميلها، ويقيس:
   - عرض الصدر (2.5 سم تحت الإبط)
   - عرض الحافة (2 سم فوق آخر القطعة)
   - الطول (من أعلى الكتف جنب الياقة لآخر القطعة)
   - طول الكم (تجريبي — لسه مش دقيق)

## 1) شغّل السيرفر

```bash
cd server
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

أو بـ Docker: `docker build -t maqasi-server server && docker run -p 8000:8000 maqasi-server`

الاختبارات: `cd server && python -m pytest -q` — وجدول الدقة: `python -m tests.report`

الموبايل والكمبيوتر لازم يكونوا على نفس الواي فاي. عنوان السيرفر هيبقى `http://<IP الكمبيوتر>:8000`.

## 2) شغّل التطبيق على موبايل حقيقي

> **مش هيشتغل على Expo Go** — الكاميرا (VisionCamera) native module، فمحتاج development build.

```bash
cd app
npm install
```

**الطريقة الأسهل (من غير Android Studio / Xcode):** EAS Build

```bash
npm i -g eas-cli
eas login
eas build --profile development --platform android   # بيطلعلك لينك APK تنزّله على الموبايل
npx expo start --dev-client                           # افتح التطبيق وامسح الـ QR
```

**أو محلياً** (محتاج Android Studio أو Xcode): `npx expo run:android` أو `npx expo run:ios`

## 3) بروتوكول الاختبار

1. افرد تيشرت على أرضية سادة بلون مختلف عنه، والأكمام مفرودة للجنب، ومفيش كسرات.
2. حط المرجع على الأرض جنب القطعة: متر مفرود، أو ورقة A4، أو كارت. عشان تقارن المراجع ببعض حط أكتر من واحد في نفس الصورة.
3. قيس بالمتر: عرض الصدر (2.5 سم تحت الإبط)، عرض الحافة، الطول، طول الكم.
4. في التطبيق: صوّر ← اختار المرجع (متر / A4 / كارت) ← حدّده ← "قيس القطعة" ← اكتب قياساتك بالمتر ← احفظ.
5. كرّر على **20 قطعة على الأقل** بألوان وأقمشة مختلفة، وعلى أكتر من موبايل.
6. الرئيسية بتعرض متوسط الخطأ لكل قياس ونسبة التجارب اللي خطأها ≤ 1 سم، **لكل مرجع لوحده**. صدّر النتايج JSON وابعتها.

**معيار النجاح المقترح:** الصدر والطول والحافة خطأهم ≤ 1 سم في 80% من التجارب.

## 4) القياس بالـ AR (flow منفصل)

من الرئيسية: **"القياس بالـ AR"**. الـ flow ده ليه سجل نتايج لوحده (`maqasi-ar-tests.json`) ومش بيخلط مع التجارب العادية.

1. افرد القطعة على الأرض (مش محتاج متر في الصورة).
2. "صوّر بالـ AR": حرّك الموبايل ببطء فوق الأرضية لحد ما يقول "الأرضية متحددة"، وخلّيه موازي للأرض (≤ 3°)، وصوّر.
   - التطبيق بيعمل hit test على شبكة 5×5 نقط على الأرضية قبل الصورة وبعدها، ويحسب px/cm من المسافات الحقيقية بين النقط (`app/src/arScale.ts`).
   - بيرفض الصورة لو الأرضية مش متحددة، أو النقط مش على نفس المستوى، أو الموبايل مايل، أو اتحرك وقت التصوير.
3. التطبيق بيقيس القطعة بمقياس الـ AR. اكتب قياساتك بالمتر جنب كل قياس عشان تشوف الفرق، واحفظ.
4. صفحة الـ AR بتعرض متوسط الفرق عن المتر ونسبة التجارب اللي فرقها ≤ 1 سم لكل قياس.

محتاج موبايل بيدعم ARCore أو ARKit، و development build جديد بعد إضافة ViroReact (`eas build --profile development --platform android`).
اختبار حساب المقياس من غير موبايل: `cd app && npm run test:ar`.

## المرحلة الجاية

- تجربة مقياس الـ AR على قطع حقيقية ومقارنته بالمتر (الـ flow اللي فوق).
- تحسين قياس الكم، وإضافة البنطلون.
